# Desktop Stats Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Stats section to the Electron desktop Dashboard showing file count, total storage size, last sync time, and connection mode.

**Architecture:** A new `GET /stats` API route returns `{ fileCount, totalBytes }` via a pgtyped SQL query. A new `stats:get` IPC channel fetches these from the desktop main process, combined with local sync state (`lastSyncAt`, `mode`). The renderer calls `window.api.stats.get()` on dashboard init and every 30 seconds, updating a new Stats section between "Sync Folder" and "Recent Activity". Dashboard window height grows from 500px to 580px.

**Tech Stack:** Express, pgtyped, Electron IPC, vanilla JS

**Prerequisites:** Desktop Plans 1–4 complete. All 24 API tests passing.

- [ ] **Step 5: Create apps/api/src/routes/stats.ts**

```typescript
import { Router } from 'express';
import { pool } from '../db';
import { requireAuth, AuthRequest } from '../middleware/auth';
import { getUserStats } from './stats.queries';

export const statsRouter = Router();

statsRouter.get('/', requireAuth, async (req: AuthRequest, res) => {
  try {
    const rows = await getUserStats.run({ userId: req.userId! }, pool);
    const row = rows[0];
    return res.json({
      fileCount: Number(row.file_count),
      totalBytes: Number(row.total_bytes),
    });
  } catch (err) {
    console.error('stats error:', err);
    return res.status(500).json({ error: 'internal server error' });
  }
});
```

**Change 1** — Add the `stats:get` handler inside `registerIpcHandlers()`, after the existing `folder:open` handler:

```typescript
ipcMain.handle('stats:get', async () => {
  try {
    const token = getStoredToken();
    if (!token) return { fileCount: 0, totalBytes: 0, lastSyncAt: null, mode: 'off' };

    const res = await axios.get(`${API_URL}/stats`, {
      headers: { Authorization: `Bearer ${token}` },
    });
    const { fileCount, totalBytes } = res.data as { fileCount: number; totalBytes: number };

    const syncStatus = getSyncStatus();
    const lastSyncAt = (await import('../../../sync/src/state')).getLastSyncAt();

    return { fileCount, totalBytes, lastSyncAt, mode: syncStatus.mode };
  } catch (err) {
    console.error('stats:get error:', err);
    return { fileCount: 0, totalBytes: 0, lastSyncAt: null, mode: 'off' };
  }
});
```

    ipcRenderer.on('activity', (_event, data) => callback(data));

- [ ] **Step 1: Add formatBytes helper**

Read the current `apps/desktop/src/renderer/app.js`. Add `formatBytes` and `formatMode` helpers after the `relativeTime` function:

```javascript
function formatBytes(bytes) {
  if (bytes === 0) return '0 KB';
  if (bytes < 1024) return '1 KB';
  if (bytes < 1024 * 1024) return Math.round(bytes / 1024) + ' KB';
  if (bytes < 1024 * 1024 * 1024) return (bytes / (1024 * 1024)).toFixed(1) + ' MB';
  return (bytes / (1024 * 1024 * 1024)).toFixed(1) + ' GB';
}

function formatMode(mode) {
  if (mode === 'sse')  return 'SSE (real-time)';
  if (mode === 'poll') return 'Polling (fallback)';
  return 'Offline';
}
```

- [ ] **Step 2: Add refreshStats() function**

Add after the `refreshStatus()` function:

```javascript
async function refreshStats() {
  try {
    const stats = await window.api.stats.get();
    document.getElementById('stat-files').textContent = stats.fileCount.toLocaleString();
    document.getElementById('stat-size').textContent = formatBytes(stats.totalBytes);
    document.getElementById('stat-last-sync').textContent =
      stats.lastSyncAt ? relativeTime(stats.lastSyncAt) : 'Never';
    document.getElementById('stat-mode').textContent = formatMode(stats.mode);
  } catch {
    // keep showing previous values on error
  }
}
```
